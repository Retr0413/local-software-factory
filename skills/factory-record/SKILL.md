# Factory の作業記録

統括が対象リポジトリの共通 Git ディレクトリを使う。ログ全文・認証情報を除き、改善材料は観測として蓄積する。

## Description から読む Skill を選ぶ

今の判断に合う行のリンクを開く。次の条件が生じたら、この表から選び直す。

| Description（使う場面） | 読む Skill・資料 |
| --- | --- |
| 完了・保留・中断の報告や同じ配達の再送を、共有 Git 記録へ保存する。 | [入力例と保存・再送](procedures/factory-record-write/SKILL.md) |
| 中断していた仕事を再開するとき、記録から元の担当・候補・未確認条件を取り出す。 | [記録からの再開](procedures/factory-record-resume/SKILL.md) |
| 手戻り・再試行・繰り返す停止を改善材料として残すとき、候補と実行の数え方を決める。 | [観測の書き方](procedures/factory-record-observations/SKILL.md) |
